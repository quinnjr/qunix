# M2 T6 — VFS Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A process can `open` a path, `read` and `write` the file it names,
`lseek` within it, `readdir` a directory, `stat` either, and `close` the
descriptor — with every path resolved by exactly one walker.

**Architecture:** The split that `qunix-bcache` validated, applied again. The
pure decisions — how a path decomposes, which descriptor a table hands out,
what an `lseek` resolves to — live in a host-tested crate with no I/O.
`kernel/src/vfs/` owns `enum Vnode`, the walker that drives it, and the mount
table; `kernel/src/vfs/tmpfs.rs` owns the one filesystem T6 needs to have
something real to resolve against.

**Tech Stack:** Rust 2024, `no_std`, `alloc`. `qunix-abi` for the syscall
contract. No `dyn`, no `Box<dyn Future>` anywhere in the I/O path.

**Spec:** `docs/superpowers/specs/2026-08-05-m2-filesystems-design.md`

**Base:** `develop` @ `fc91d60` (M2 T5, the buffer cache, merged).

## Global Constraints

Copied from the spec and `CLAUDE.md`. Every task's requirements include these.

- **`enum Vnode`, never `dyn Vnode`.** `async fn` in a trait is not
  dyn-compatible without `Pin<Box<dyn Future>>`, which is a heap allocation on
  every read. Adding a filesystem means adding a variant; that closed set is
  the accepted cost.
- **No dentry cache.** Path resolution goes directly against the filesystem.
  Caching is a measured optimisation, not a starting assumption.
- **One path walker.** Symlink-loop bounding, mountpoint crossing, `.` and
  `..`, and permission checks happen in exactly one function. This is the
  direct answer to M1's dominant defect class: every Critical found there was a
  correct guard applied to one of two places.
- **No panics on filesystem content.** Everything read from a filesystem is
  attacker-controlled input in the sense the ELF loader's input is. Refuse with
  an errno. The rule that produced `qunix-elf`, where twelve of sixteen tests
  assert refusal, applies unchanged.
- **No allocation reachable from the writeback path.** Designed against from
  T5, not discovered later.
- **`no_std`**, edition-2024 `#[unsafe(...)]` attribute forms, no `static mut`,
  no floating point, comments explain *why*.
- **Every commit leaves `cargo xtask test` green**, both boots.

## Scope decision: T6 ships a working filesystem

The spec's task sequence puts tmpfs at T7, but T6's deliverables include
`read`, `write`, `readdir` and `stat`. Those are operations *on a filesystem*,
so T6 cannot be tested without one, and a stub is forbidden.

T6 therefore ships `Vnode::Tmpfs` as a working in-memory tree: directories,
byte files, and the five operations above. T7 adds what T6 does not need —
`create`, `unlink`, `mkdir`, `rmdir`, `rename`, `truncate`, and the growth
policy. The alternative, mounting devfs (T8) instead, was rejected because a
flat directory cannot exercise nested walking, `..`, or mountpoint crossing,
which are the parts of T6 most likely to be wrong.

Record this in Execution Deviations as D1 when the first task lands.

```rust
fn every_errno_is_negative_and_distinct() {

    // Distinct because a caller that cannot tell `NoEntry` from `NotDirectory`
```

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
#[repr(u64)]
pub enum Sys {
    Exit = 0,
    Write = 1,
    Yield = 2,
    GetPid = 3,
    Open = 4,
    Read = 5,
    Close = 6,
    Lseek = 7,
    Readdir = 8,
    Stat = 9,
}

impl Sys {
    pub const fn from_raw(nr: u64) -> Option<Self> {
        match nr {
            0 => Some(Self::Exit),
            1 => Some(Self::Write),
            2 => Some(Self::Yield),
            3 => Some(Self::GetPid),
            4 => Some(Self::Open),
            5 => Some(Self::Read),
            6 => Some(Self::Close),
            7 => Some(Self::Lseek),
            8 => Some(Self::Readdir),
            9 => Some(Self::Stat),
            _ => None,
        }
    }
}

/// Error returns. Negative so a syscall can return a non-negative result or an
/// error in one register, as Linux does.
///
/// The values are qunix's own, not Linux's: `qunix-abi` is the *native* ABI,
/// and the Linux personality translates. Distinctness is what matters, and is
/// asserted.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
#[repr(i64)]
pub enum Errno {
    Ok = 0,
    BadSyscall = -1,
    BadAddress = -2,
    BadArgument = -3,
    /// No such file or directory.
    NoEntry = -4,
    /// A path component that had to be a directory was not one.
    NotDirectory = -5,
    /// A directory was named where a file was required.
    IsDirectory = -6,
    /// The descriptor is not open in this process.
    BadDescriptor = -7,
    /// The path, or one component of it, is longer than the kernel accepts.
    NameTooLong = -8,
    /// Symlink resolution did not terminate within the bound.
    TooManyLinks = -9,
    /// The process's descriptor table is full.
    TooManyFiles = -10,
    /// The filesystem does not implement this operation.
    NotSupported = -11,
}

/// How a file was opened.
///
/// A newtype over the bits rather than an enum, because the access mode and the
/// future creation flags are independent. `from_bits` refuses anything
/// undefined: the word is userspace input, and accepting an unknown bit means a
/// flag defined later silently inherits behaviour from programs written before
/// it existed.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct OpenFlags(u32);

impl OpenFlags {
    pub const READ: Self = Self(1 << 0);
    pub const WRITE: Self = Self(1 << 1);
    /// Every bit this kernel defines. The mask is derived from the constants
    /// rather than written out, so adding one cannot leave the guard behind.
    const KNOWN: u32 = Self::READ.0 | Self::WRITE.0;

    pub const fn bits(self) -> u32 {
        self.0
    }

    pub const fn from_bits(bits: u32) -> Option<Self> {
        if bits & !Self::KNOWN != 0 { None } else { Some(Self(bits)) }
    }

    pub const fn is_readable(self) -> bool {
        self.0 & Self::READ.0 != 0
    }

    pub const fn is_writable(self) -> bool {
        self.0 & Self::WRITE.0 != 0
    }
}

/// The reference point for [`Sys::Lseek`].
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
#[repr(u64)]
pub enum Whence {
    Set = 0,
    Current = 1,
    End = 2,
}

impl Whence {
    pub const fn from_raw(raw: u64) -> Option<Self> {
        match raw {
            0 => Some(Self::Set),
            1 => Some(Self::Current),
            2 => Some(Self::End),
            _ => None,
        }
    }
}

/// What `stat` writes into the user's buffer.
///
/// `repr(C)` because userspace reads it field by field. The padding is explicit
/// so the layout is the same on both sides of the call rather than the same by
/// luck.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
#[repr(C)]
pub struct Stat {
    pub size: u64,
    pub inode: u64,
    pub kind: u32,
    pub mode: u32,
    pub links: u64,
}

/// What `readdir` writes for one entry.
#[derive(Debug, Clone, Copy)]
#[repr(C)]
pub struct DirEntry {
    pub inode: u64,
    pub kind: u32,
    pub name_len: u32,
    pub name: [u8; NAME_MAX],
}

/// The longest single path component, in bytes.
pub const NAME_MAX: usize = 248;
/// The longest whole path, in bytes.
pub const PATH_MAX: usize = 4096;

/// What a [`Stat`] or [`DirEntry`] names.
pub const KIND_FILE: u32 = 1;
pub const KIND_DIRECTORY: u32 = 2;
```

```rust
//! Splitting a path into what a walker visits, and nothing else.
//!
//! No I/O and no opinion about what the components mean: `..` at a mountpoint
//! and `..` at the root resolve differently, and only the walker knows which
//! it is looking at.

use qunix_abi::{NAME_MAX, PATH_MAX};

/// One step of a path.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Component<'a> {
    /// `.`
    Current,
    /// `..`
    Parent,
    /// Anything else.
    Name(&'a str),
}

/// Why a path could not be decomposed.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum PathError {
    /// The empty string. Refused rather than read as `.`, so a path built by
    /// concatenation that came out empty is an error at the call rather than
    /// the working directory returned successfully.
    Empty,
    /// Longer than `PATH_MAX`.
    TooLong,
    /// One component is longer than `NAME_MAX`, which is the array a
    /// `DirEntry` copies it into.
    ComponentTooLong,
}

/// A validated path, borrowed from the caller's buffer.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Path<'a> {
    raw: &'a str,
    absolute: bool,
}

impl<'a> Path<'a> {
    /// Validates `raw` and records whether it is absolute.
    ///
    /// Both bounds are checked here rather than while walking, so a path that
    /// cannot be represented is refused before any filesystem is touched.
    pub fn parse(raw: &'a str) -> Result<Self, PathError> {
        if raw.is_empty() {
            return Err(PathError::Empty);
        }
        if raw.len() > PATH_MAX {
            return Err(PathError::TooLong);
        }
        if raw.split('/').any(|component| component.len() > NAME_MAX) {
            return Err(PathError::ComponentTooLong);
        }
        Ok(Self { raw, absolute: raw.starts_with('/') })
    }

    pub fn is_absolute(&self) -> bool {
        self.absolute
    }

    /// The components a walker visits, in order.
    ///
    /// Empty segments are dropped, which is what collapses `//a///b/` to
    /// `a`, `b`. A walker that received the empty ones would look up `""` in a
    /// directory: at best a failure for the wrong reason, at worst a match
    /// against an entry whose name really is empty.
    pub fn components(&self) -> impl Iterator<Item = Component<'a>> + '_ {
        self.raw.split('/').filter(|s| !s.is_empty()).map(|s| match s {
            "." => Component::Current,
            ".." => Component::Parent,
            name => Component::Name(name),
        })
    }
}
```

```rust
struct Handle(u32);

#[test]
fn descriptors_are_handed_out_lowest_free_first() {
    // The rule programs actually depend on: `close(0); open(..)` must return
    // 0, which is how a shell redirects stdin. A table that always appended
    // would satisfy every other test here and break that.
    let mut table = FdTable::new();
    assert_eq!(table.insert(Handle(10)), Ok(0));
    assert_eq!(table.insert(Handle(11)), Ok(1));
    assert_eq!(table.insert(Handle(12)), Ok(2));
    assert_eq!(table.remove(1).map(|h| h.0), Ok(11));
    assert_eq!(table.insert(Handle(13)), Ok(1), "the freed descriptor was not reused");
}

#[test]
fn a_closed_descriptor_is_not_readable_and_closing_it_twice_is_refused() {
    // Both directions of the same fact. A `get` that still answered after a
    // close is a use-after-close returning somebody else's file once the
    // number is reused; a second `remove` that succeeded would return a handle
    // the caller already owns.
    let mut table = FdTable::new();
    let fd = table.insert(Handle(1)).unwrap();
    assert!(table.get(fd).is_some());
    assert!(table.remove(fd).is_ok());
    assert!(table.get(fd).is_none(), "a closed descriptor still resolved");
    assert_eq!(table.remove(fd), Err(FdError::BadDescriptor));
}

#[test]
fn a_descriptor_that_was_never_opened_is_refused() {
    let mut table: FdTable<Handle> = FdTable::new();
    assert!(table.get(0).is_none());
    assert!(table.get(FdTable::<Handle>::CAPACITY).is_none(), "an index past the end resolved");
    assert_eq!(table.remove(7), Err(FdError::BadDescriptor));
}

#[test]
fn a_full_table_refuses_rather_than_evicting() {
    // A table that reused an occupied slot would hand two files one
    // descriptor, and the first owner's next read would be the second's file.
```

```rust
//! The per-process descriptor table.

/// Why a descriptor operation was refused.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum FdError {
    /// Every descriptor is in use.
    Full,
    /// The descriptor is not open in this process.
    BadDescriptor,
}

/// A fixed table of open files.
///
/// Fixed for the same reason the buffer cache's is: a table that grows is a
/// table that allocates, and this one is reached from paths that must not.
/// Generic over the payload so the allocation rules can be tested on the host
/// without a `Vnode` to put in it.
pub struct FdTable<T> {
    slots: [Option<T>; Self::CAPACITY],
}

impl<T> FdTable<T> {
    /// Descriptors per process.
    pub const CAPACITY: usize = 64;

    pub fn new() -> Self {
        Self { slots: [const { None }; Self::CAPACITY] }
    }

    /// Installs `value` at the lowest free descriptor.
    ///
    /// Lowest-free rather than next-free, because programs depend on it:
    /// `close(0)` followed by an `open` is how a shell redirects standard
    /// input, and it only works if the new file lands on 0.
    pub fn insert(&mut self, value: T) -> Result<usize, FdError> {
        let index = self.slots.iter().position(Option::is_none).ok_or(FdError::Full)?;
        self.slots[index] = Some(value);
        Ok(index)
    }

    pub fn get(&self, fd: usize) -> Option<&T> {
        self.slots.get(fd)?.as_ref()
    }

    pub fn get_mut(&mut self, fd: usize) -> Option<&mut T> {
        self.slots.get_mut(fd)?.as_mut()
    }

    /// Closes a descriptor, returning what it held.
    ///
    /// Refuses one that is not open. Returning `Ok` for a double close would
    /// let a program close a descriptor another part of it had since opened on
    /// the same number.
    pub fn remove(&mut self, fd: usize) -> Result<T, FdError> {
        self.slots.get_mut(fd).and_then(Option::take).ok_or(FdError::BadDescriptor)
    }
}

impl<T> Default for FdTable<T> {
    fn default() -> Self {
        Self::new()
    }
}
```

```rust
//! Where an `lseek` lands.

use qunix_abi::Whence;

/// Why a seek was refused.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum SeekError {
    /// The result is before the start of the file.
    Negative,
    /// The result does not fit in a `u64`.
    Overflow,
}

/// The absolute offset `whence`/`offset` names.
///
/// Every step is checked. `base as i64 + offset` wraps on a `u64` file offset,
/// and a wrapped offset is not a failure the caller sees: it is a read from
/// somewhere else in the file, and once a filesystem multiplies it by a block
/// size, from somewhere else on the disk.
///
/// Seeking *past the end* is legal and deliberate -- it is how a sparse file
/// is written -- so only the two impossibilities are refused.
pub fn resolve_seek(
    current: u64,
    size: u64,
    offset: i64,
    whence: Whence,
) -> Result<u64, SeekError> {
    let base = match whence {
        Whence::Set => 0,
        Whence::Current => current,
        Whence::End => size,
    };
    if offset >= 0 {
        base.checked_add(offset as u64).ok_or(SeekError::Overflow)
    } else {
        // `unsigned_abs` rather than `-offset`, which overflows for i64::MIN.
        base.checked_sub(offset.unsigned_abs()).ok_or(SeekError::Negative)
    }
}
```

```rust
use alloc::sync::Arc;
use alloc::vec::Vec;
use qunix_hal_x86_64::Irq;

/// What a node is. The contents are behind the lock; the kind is not, because

    Directory(BTreeMap<String, TmpfsNode>),
}

pub struct TmpfsNode {
```

**The user-pointer rule.** Every buffer a syscall is handed is userspace input.

canonical lower half; a syscall that writes *out* needs the same check before
the write, not after. There is one helper for each direction and neither is
open-coded — same reason there is one walker.

**`sys_write`'s change of meaning.** It currently takes `(ptr, len)` and prints
to the console. It becomes `(fd, ptr, len)`. `kernel/user/init.s` calls it and
must be updated in the same commit, or the boot prints nothing and every test
that asserts the ring-3 message fails for a reason that looks unrelated.

```rust
#[test_case]
fn opening_reading_and_closing_a_file_round_trips_through_descriptors() {
    let mut process = test_process();
    let fd = sys_open_in(&mut process, "/hello", OpenFlags::READ).expect("open failed");
    let mut buf = [0u8; 32];
    let n = sys_read_in(&mut process, fd, &mut buf).expect("read failed");
    assert_eq!(&buf[..n], b"hello, vfs");
    assert!(sys_close_in(&mut process, fd).is_ok());
    // The descriptor is gone: a read through it must be refused, not answered
    // from whatever the slot still held.
    assert_eq!(sys_read_in(&mut process, fd, &mut buf), Err(Errno::BadDescriptor));
}

#[test_case]
fn a_read_advances_the_offset_and_a_second_read_continues() {
    // The offset lives on the descriptor, not the file: two descriptors on one
    // file read independently, which is what makes `open` twice work.
    let mut process = test_process();
    let a = sys_open_in(&mut process, "/hello", OpenFlags::READ).unwrap();
    let b = sys_open_in(&mut process, "/hello", OpenFlags::READ).unwrap();
    let mut buf = [0u8; 5];
    assert_eq!(sys_read_in(&mut process, a, &mut buf), Ok(5));
    assert_eq!(&buf, b"hello");
    assert_eq!(sys_read_in(&mut process, a, &mut buf), Ok(5));
    assert_eq!(&buf, b", vfs");
    // `b` has not moved.
    assert_eq!(sys_read_in(&mut process, b, &mut buf), Ok(5));
    assert_eq!(&buf, b"hello", "two descriptors shared one offset");
}

#[test_case]
fn a_descriptor_opened_read_only_refuses_a_write() {
    // The check the flags exist for. Without it `OpenFlags` is decoration and
    // a program opens a file for reading and modifies it.
    let mut process = test_process();
    let fd = sys_open_in(&mut process, "/hello", OpenFlags::READ).unwrap();
    assert_eq!(sys_write_in(&mut process, fd, b"x"), Err(Errno::BadArgument));
    let rw = sys_open_in(&mut process, "/hello", OpenFlags::WRITE).unwrap();
    assert!(sys_write_in(&mut process, rw, b"x").is_ok());
}

#[test_case]
fn lseek_moves_the_offset_and_refuses_a_negative_result() {
    let mut process = test_process();
    let fd = sys_open_in(&mut process, "/hello", OpenFlags::READ).unwrap();
    assert_eq!(sys_lseek_in(&mut process, fd, 7, Whence::Set), Ok(7));
    let mut buf = [0u8; 8];
    let n = sys_read_in(&mut process, fd, &mut buf).unwrap();
    assert_eq!(&buf[..n], b"vfs");
    assert_eq!(sys_lseek_in(&mut process, fd, -100, Whence::Current), Err(Errno::BadArgument));
    // And the refused seek left the offset alone rather than half-applied.
    assert_eq!(sys_lseek_in(&mut process, fd, 0, Whence::Current), Ok(10));
}

#[test_case]
fn readdir_walks_a_directory_one_entry_at_a_time_and_ends() {
    let mut process = test_process();
    let fd = sys_open_in(&mut process, "/", OpenFlags::READ).unwrap();
    let mut seen = alloc::vec::Vec::new();
    while let Some(entry) = sys_readdir_in(&mut process, fd).expect("readdir failed") {
        seen.push(dir_entry_name(&entry).into());
    }
    assert!(seen.contains(&alloc::string::String::from("hello")), "readdir missed a child: {seen:?}");
    // It ends. A readdir that never returned `None` is an infinite loop in
    // every program that uses it correctly.
    assert!(sys_readdir_in(&mut process, fd).unwrap().is_none());
}

#[test_case]
fn stat_reports_the_size_and_kind_and_refuses_a_path_that_is_not_there() {
    let mut process = test_process();
    let stat = sys_stat_in(&mut process, "/hello").expect("stat failed");
    assert_eq!(stat.size, 10);
    assert_eq!(stat.kind, KIND_FILE);
    let dir = sys_stat_in(&mut process, "/sub").unwrap();
    assert_eq!(dir.kind, KIND_DIRECTORY);
    assert_eq!(sys_stat_in(&mut process, "/absent").err(), Some(Errno::NoEntry));
}

#[test_case]
fn a_syscall_refuses_a_user_pointer_outside_the_lower_half() {
    // The kernel half is not the caller's to read or to have written into.
    // Refused before the copy, because a copy that faults in ring 0 panics.
    let mut process = test_process();
    let fd = sys_open_in(&mut process, "/hello", OpenFlags::READ).unwrap();
    assert_eq!(
        sys_read_raw(&mut process, fd, 0xffff_8000_0000_0000, 16),
        Errno::BadAddress as i64
    );
    assert_eq!(
        sys_open_raw(&mut process, 0xffff_8000_0000_0000, 8, OpenFlags::READ.bits()),
        Errno::BadAddress as i64
    );
}
```

Three `#[cfg(test)]` helpers, all in `kernel/src/syscall.rs`:

- `test_process() -> Process` calls `vfs_test_reset()` and returns a `Process`
  with an empty `FdTable` and no address space. It has no address space because
  these tests exercise the syscall *bodies*; the entry path and a real user
  address space are Task 8's subject, and a test that needed both would fail
  for either reason.
- `sys_*_in(&mut Process, ..)` take a `Process` and Rust slices, so a body can
  be called without a user pointer.
- `sys_read_raw`/`sys_open_raw(&mut Process, ..)` take the raw register
  arguments and return the raw `i64`, which is what the pointer test needs —
  the whole point of it is the value an out-of-range pointer produces.

- [ ] **Step 3: Give the process a descriptor table**

`Process` gains `files: FdTable<OpenFile>`, where

```rust
/// One open descriptor: what it names, how it was opened, and where it is.
///
/// The offset lives here rather than on the `Vnode`, because two `open`s of
/// one file must read independently -- which is the whole reason a descriptor
/// is not just a pointer to a file.
pub struct OpenFile {
    node: Vnode,
    flags: OpenFlags,
    offset: u64,
    /// How far `readdir` has got. Separate from `offset`: a directory's
    /// entries are not bytes, and sharing the field would make an `lseek` on a
    /// directory move the enumeration to a position that is not an entry.
    dir_cursor: usize,
}
```

- [ ] **Step 4: Implement the syscalls**

Each one: validate the user pointers first, then resolve, then act. `sys_open`
resolves the path and installs an `OpenFile`; `sys_read`/`sys_write` go through
the descriptor and advance `offset`; `sys_lseek` calls `resolve_seek` and
assigns only on success; `sys_readdir` returns one entry and advances
`dir_cursor`; `sys_stat` resolves and fills a `Stat`; `sys_close` removes.

Map `VfsError` and `FdError` onto `Errno` in one function, so two syscalls
cannot disagree about what `NoEntry` means.

### Task 8: A ring-3 program that uses it

**Files:**
- Modify: `kernel/user/init.s`, `xtask/src/userland.rs` if the program grows
  past what the current assembly step handles
- Modify: `kernel/src/main.rs` (mount the root filesystem at boot)

**Why this task exists.** Every test so far runs in ring 0 with a `Process`
built by a helper. None of them proves a *userspace* program can open a file —
which is the deliverable. The gap between "the syscall function works" and "the
syscall works" is the SYSCALL entry path, the user pointer validation against a
real user address space, and the fd table living on the real process.

- [ ] **Step 1: Mount the root filesystem at boot**

`kmain` calls `vfs::init()`, which mounts the tmpfs root at `/`. Unlike
`bcache::init` (see that plan's D13), this one *does* get a caller now, because
a userspace program is about to resolve a path through it.
